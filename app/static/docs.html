并行处理

并行分两层，可在设置页调整（即时生效，持久化到 dirs.settings_file，默认 /data/settings.json）：

  • concurrency（并行任务数，默认 1）：同时转码几个文件。增大后多个任务同时进行，会显著提高 CPU/内存占用。
  • av1an_workers（任务内切片并行，默认 0）：每个任务内部 av1an 用多少线程并行编码切片；0 = 自动（av1an 按 CPU 核数分配）。

各取值对资源占用的影响：concurrency × av1an_workers 约等于峰值同时运行的编码进程数。减小编号即时生效：已排队的任务不受影响，当前任务完成后对应的 worker 会自动退出。

工作流程

默认不会自动入队任何文件（watcher.enabled: false）：只有通过首页表单 / API POST /api/jobs 手动指定的文件或目录才会被转码。如需恢复自动监视，在 config.yaml 中设置 watcher.enabled: true。

提交的文件会分析（Dolby Vision P5/P7/P8 → HDR10（保留/附带 RPU），HDR10/HLG/SDR 直接编码），随后按预设的码率/质量参数编码输出为 AV1（SVT-AV1）。

  • 已是 AV1 的源默认跳过（skip_existing_av1）。
  • 成功后源文件默认保留在原位置。可选：在设置页开启「删除源文件」（需要二次确认，危险操作）。

输出行为

默认（dirs.output/dirs.rpu 为 null）转码输出到源文件所在目录下的 av1/ 子目录：

movies/
├── Big Buck Bunny.mkv        # 源文件
└── av1/
    ├── Big Buck Bunny.av1.mkv    # 转码输出
    └── rpu/
        └── Big Buck Bunny.rpu.bin   # 抽取的 Dolby Vision RPU（仅 DV 源且 save_rpu=true）

若在 config.yaml 中配置了固定的 dirs.output/dirs.rpu，则所有输出集中到这些目录。监视器（watcher）会排除 av1/work/rpu 目录，避免把转码输出再次入队。

预设与编码参数

预设可在设置页添加/编辑/删除并持久化（存于 dirs.presets_file，默认 /data/presets.json）。自定义预设可覆盖内置同名预设，内置预设删除后自动恢复 config.yaml 中的定义。

自定义参数（临时覆盖，不落盘）

首页表单的“自定义参数”框，或 CLI --custom key=value（可重复），按 key=value 逗号/分号分隔。值会覆盖所选预设的同名字段：

crf=24,preset=3,target_quality=75-85,film_grain_denoise=true

数字字段自动转 int（crf/preset/film_grain/passes/keyint/extra_split_sec/min_scene_len/tune），布尔字段接受 true/false/1/0（film_grain_denoise），其余按字符串（target_quality、additional_video_params、pixel_format）。预设选 custom 时以默认视频参数为基准，全部由自定义参数决定。

Dolby Vision / HDR

环境变量覆盖

任何配置均可通过环境变量覆盖（容器内优先于 config.yaml）：AV1TC_<段>_<键>，例如：

AV1TC_TRANSCODE_VIDEO_CRF=26
AV1TC_WEB_PORT=9090
AV1TC_WATCHER_MIN_SIZE_MB=5

布尔值接受 1/true/yes/on，数字自动转换。

CLI 用法

python3 -m app.cli run                    # 完整运行（监视+队列+Web）
python3 -m app.cli process <file> --single --custom crf=24 --custom preset=3
python3 -m app.cli process <file> -p compact
python3 -m app.cli scan                    # 把输入目录现有文件全部入队
python3 -m app.cli presets                 # 查看当前预设
python3 -m app.cli status / cancel / check
